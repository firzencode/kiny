# Kiny Shelf · 网页书库阅读器

在浏览器里阅读 Kiny 互动叙事故事包（`.kip`）的书库应用。导入 `.kip` → 进书架 → 阅读，带存档 / 读档。纯静态、可部署到任意网站，故事与存档都留在读者本机（无服务器、不上传）。

## 功能

- **导入 `.kip`**：点「导入故事」选择文件，或把 `.kip` 拖进窗口。
- **持久书库**：导入的故事存在浏览器本地（IndexedDB），刷新后仍在；列出封面 / 书名 / 作者 / 简介，可删除。
- **阅读**：逐字揭示、选项分支、背景与音效，由 Kiny 引擎与播放器驱动。
- **存档 / 读档**：自动续读档（随进度更新）+ 手动多档，存在浏览器本地（localStorage）。书架按是否有续读进度显示「继续 / 重新开始」。

## 构建

shelf 是 Kiny 单一代码库中的一个子项目，依赖同库的引擎与播放器。在**代码库根目录**：

```bash
npm run install:all      # 安装各子项目依赖
npm run build:core       # 先构建引擎 / 播放器（shelf 的依赖）
npm --prefix shelf run build
```

产物在 `shelf/dist/`，使用相对路径引用资源——把整个 `dist/` 目录部署到网站的任意位置（域名根、子目录、静态托管）经任意静态服务器访问即可（应用用到 ES 模块与本地存储，需经 HTTP 提供，不支持 `file://` 双击打开）。

## 开发

```bash
npm run dev:shelf        # 启动本地开发服务器
npm --prefix shelf test  # 跑测试
```
